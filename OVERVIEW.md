Chat Polish customizes Paseo’s chat timeline, rich text, themes and fonts from a live preview dashboard. It can display tool calls as compact rows, merge thoughts and tool calls between replies, show image previews, and add turn recaps.

Requires Paseo 0.11.2 or newer and npm on the daemon host for its locked dependency preparation. Open Chat Polish in the sidebar to configure themes, messages, steps and rich text. Individual tool rows require Settings → Appearance → Tool call display set to Detailed.

The plugin reads agent timelines, provider and model metadata, and app appearance settings. It stores plugin preferences on the daemon; appearance changes also update local app settings. On desktop and web it uses Paseo app DOM internals to restyle chat, composer, permission cards and diagrams, so Paseo app updates can affect these integrations. It reads image files referenced in replies from the daemon filesystem and sends their contents to the connected client; image paths are not restricted to a workspace, and files over 12 MiB are skipped. Remote image URLs are loaded by the client. Turn recaps append changed-file summaries and failed-command excerpts to the agent timeline. The plugin presents tool commands from the timeline but does not run them.
